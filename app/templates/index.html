Review to Reel

  • From real reviews

    Built from saved guest reviews, or a batch you paste in.

How it’s built

A real app, not a slide deck. You can sign in, write to a database, and open a public link.

FastAPI

Python web app with HTML pages and a JSON API.

JWT auth

Sign in with an httpOnly cookie or a Bearer token.

SQLite

Meetings, reviews, coupons and briefs live in a real database.

OpenAI Whisper + chat

Transcription and structured prompts when an API key is set.

Deployed on Vercel

A public demo you can open from a resume or a message.
